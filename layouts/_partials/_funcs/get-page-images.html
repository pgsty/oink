{{- /* Override of Hugo's embedded helper of the same name. Hugo's `opengraph.html`, `twitter_cards.html`, and `schema.html` all read their images from this one partial, so overriding it is the whole of the wiring: a page's featured image becomes the image its social card carries, and the three metadata templates stay Hugo's. `featured-image-resolve.html` owns the page-level decision -- `images` on the page, a `**featured*` / `*feature*` / `{*cover*,*thumbnail*}` resource, then `images` inherited from a section cascade. Site-wide `params.images` is the last resort, and only here: it is a social card, never a rendered thumbnail. OINK carries one representative image. When `images` contains several entries, only the first selected entry reaches Open Graph, Twitter, and schema metadata, regardless of whether it resolves as a Resource, static path, or remote URL. Every path reaches the shared image URL policy, so a card cannot carry a URL the theme would refuse to render, and cannot drop a deployment subpath the rendered image keeps. Input: a page. Returns: a slice of dicts carrying `Image`, `RelPermalink`, and `Permalink`, the shape the embedded metadata templates consume. */ -}} {{- $imgs := slice }} {{- $resources := .Resources.ByType "image" }} {{- $imgParams := slice }} {{- $found := partialCached "featured-image-resolve.html" . .RelPermalink }} {{- with $found.resource }} {{- $imgs = $imgs | append (dict "Image" . "RelPermalink" .RelPermalink "Permalink" .Permalink) }} {{- else }} {{- if $found.href }} {{/* The resolver selected `images`; OINK's card contract is one image. */}} {{- $imgParams = first 1 (partial "images-param.html" .Params.images) }} {{- else }} {{- $imgParams = first 1 (partial "images-param.html" site.Params.images) }} {{- end }} {{- end }} {{- range $imgParams }} {{- $img := . }} {{- $validated := partial "content/url.html" (dict "name" "featured-image" "parameter" "images" "position" $.Path "value" $img "kind" "image" ) }} {{- if $validated.external }} {{- $imgs = $imgs | append (dict "RelPermalink" $img "Permalink" $img) }} {{- else }} {{/* Internal image: check page resources first, then global resources. */}} {{- with or ($resources.GetMatch $img) (resources.GetMatch $img) -}} {{- $imgs = $imgs | append (dict "Image" . "RelPermalink" .RelPermalink "Permalink" .Permalink) }} {{- else }} {{- $imgs = $imgs | append (dict "RelPermalink" $validated.href "Permalink" (strings.TrimPrefix "/" $img | absURL)) }} {{- end }} {{- end }} {{- end }} {{- return $imgs }}
