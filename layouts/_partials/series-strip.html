{{- /* The series strip: one line above an article saying which series it belongs to, where the reader is in it, and what comes next, with the whole list behind a disclosure. No JavaScript, no page-store flag, no bundle member. A site activates it by declaring the taxonomy -- `taxonomies: {series: series}` is the entire switch. Where it is not declared, `series:` in front matter stays an ordinary page parameter that nothing reads, and this partial renders nothing. Two rules the markup encodes: * a member of several series gets one strip, for the first term it names; * a series of one member gets none, because a list of one has nowhere to navigate to. Reading order, the ordinal, and the next link all come from series-pages.html, so the strip and the term page can never disagree. Numbering, cross-references, and aggregate output are Book's, not this: a series is a reading path through independent articles. */ -}} {{- $page := . -}} {{- with index $page.Site.Taxonomies "series" -}} {{- with $page.GetTerms "series" -}} {{- $term := index . 0 -}} {{- $members := partial "series-pages.html" $term -}} {{- $total := len $members -}} {{- $part := 0 -}} {{- $next := false -}} {{- range $index, $member := $members -}} {{- if eq $member.RelPermalink $page.RelPermalink -}} {{- $part = add $index 1 -}} {{- if lt $part $total }}{{ $next = index $members $part }}{{ end -}} {{- end -}} {{- end -}} {{- if and (gt $total 1) (gt $part 0) }}
