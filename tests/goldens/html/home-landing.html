FAQ

What people ask about this page

Answers are block Markdown, so lists and multiple paragraphs work as written.

Is it really one file?

Everything between the navbar and the footer is. Navigation comes from hugo.yaml, the footer from data/footer/en.yaml, and every block in between from data/home/en.yaml.

Does each language need its own file?

A single-language site can use one data/home.yaml. This site is bilingual, so it uses data/home/en.yaml and data/home/zh.yaml.

Can one section type appear more than once?

Yes — give each entry a different key:

  • { type: gallery, key: products }
  • { type: gallery, key: case_studies }

The three logo walls on this page are one section type reading three different blocks.

What happens when url is missing?

The item renders as ordinary content — no empty link, no broken link. Two of the three cards above have no url.

Free-form Markdown
