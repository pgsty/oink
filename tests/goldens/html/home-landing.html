FAQ

Common questions

Answers use block Markdown, so lists and multiple paragraphs work as expected.

Can I use one data/home.yaml file?

Yes. Single-language sites can use one file; multilingual sites can use data/home/en.yaml, data/home/zh.yaml, and so on.

Can I repeat a Section type?

Yes. Give each entry a different key:

  • { type: gallery, key: products }
  • { type: gallery, key: case_studies }
What happens when url is missing?

The item renders as normal content without an empty or broken link.
