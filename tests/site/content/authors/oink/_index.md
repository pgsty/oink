Release notes and project announcements are signed by the project. An author
is a taxonomy term, so this page is its term page: the title is the display
name, this body is the long introduction, and the bundled `featured.svg` —
the theme's own mark — is the portrait the byline shows, framed round like
any other avatar. An SVG needs no image processing to serve here.
