OINK 把界面文字、正文、标题、标签与代码放在各自的排版角色里。
中文正文用于验证明确的 CJK 回退与换行行为。

## 配置主题

行内 `code` 与下面这个代码块演练 Bootstrap 的等宽字体桥接：

```yaml
params:
  ui:
    typography: technical
```

### 构建站点

只用 Hugo Extended，不需要任何前端包管理器。

### 检查结果

看一看文档外壳、打印视图，以及本地托管的字体。

| 角色 | 用途 |
| --- | --- |
| UI | 导航与控件 |
| 正文 | 长篇文档正文 |
| 等宽 | 代码与终端输出 |

> 排版预设只更换字体角色，不改变页面结构。
